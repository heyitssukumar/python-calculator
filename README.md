# 🧮 Python Calculator

A simple command-line calculator built using Python. This project performs basic arithmetic operations and allows users to continue calculations using the previous result.

## ✨ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)
- Continue calculations using the previous result
- Input validation for numbers
- Error handling for division by zero
- Option to exit the calculator

## 🛠️ Technologies Used

- Python 3
- VS Code

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```
